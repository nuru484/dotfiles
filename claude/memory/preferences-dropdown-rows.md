Each preference is one row: name and one-line hint left, a select right (full width under the words on a phone), applied the moment it is chosen. Radio-card grids ("junk stacked of cards") and Edit-then-Save sections were rejected.

**Why:** owner, 7 Oct 2026, on /me/preferences Appearance: "what happens to using say a drop to select... like how shadcn does it for the theme selection".

**How to apply:** any new personal or quick setting uses this row; the declared pattern is "Choices that apply at once" in lfms-web docs/PATTERNS.md.
