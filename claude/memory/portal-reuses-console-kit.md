The client portal is built from the same kit and rules as the console: record list rows, confirmations before irreversible acts (sign out included), page measures, a profile with its own photo, a theme toggle. Never a different, thinner design.

**Why:** owner, 8 Oct 2026: the portal UI was "below par ... we already have established ui systems in the lfms system itself, so it was just a matter of doing same things there".

**How to apply:** any portal screen copies its console equivalent; owner will list further portal faults in a dedicated session.
