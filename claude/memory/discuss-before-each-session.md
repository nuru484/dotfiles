Before starting any build-plan step or session, tell the owner what it will build (scope, screens, data, what is left out) and discuss it; proceed only once they agree.

**Why:** owner, 3 Oct 2026: "before you build any step or session, you tell me, and we discuss about it first before you proceed, so that you will not generate boilerplates on wards". The Documents restructure grew into a 17-part spec and slowed everything; the owner wants to shape scope up front and move fast.

**How to apply:** at each session boundary, stop and give a short brief (what, why, size, what is deferred), wait for the owner. Small fixes inside an agreed session need no new discussion. Overrides [[never-stop-between-milestones]] and the "never stop" instructions in older handoffs. Related: [[lfms-handoff-2026-10-03]].
