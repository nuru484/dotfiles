# Shared engineering guidance

Read `~/.config/dotfiles-agent-instructions/engineering.md` before engineering work.
Shared skills are installed alongside Codex-only skills in `~/.agents/skills`.
Use the active tool inventory; Claude plugins and memory are not assumed available.
For `$graphify`, load the graphify skill and its Codex integration reference.
Project instructions and installed framework documentation take precedence over
stack examples in personal skills. Keep credentials and session state machine-local.
