# Visual direction and composition

Use this skill when choosing or changing the visual language. For small edits,
retain the existing design system instead of restyling the surrounding interface.
The user's explicit references, established brand, and accessibility needs outrank
personal aesthetic defaults. Do not turn a font or palette preference into a ban
on faithfully implementing a supplied design.

Identify the surface's job: persuade, operate, read, or showcase. Derive typography,
spacing, density, and accent usage from the audience, content, and existing assets.
Choose a coherent direction and proceed; ask only when materially different readings
of the brief cannot be resolved from context. Avoid invented numerical design scores.

## Defaults when the brief is silent

Prefer restrained typography, consistent spacing/radii, and an intentional accent.
Avoid default purple gradients, beige-and-brass luxury styling, repetitive feature
cards, excessive glass, or arbitrary serif accents. These are default-avoidance
preferences, not reasons to override a requested brand. Semantic status colors may
coexist with the primary accent. Do not add shadows unless explicitly requested.

Never invent testimonials, customer logos, performance figures, or factual claims.
Use supplied content; when content is missing, label temporary placeholders clearly
and report what the user must supply. Do not block layout work on missing imagery.
Preserve third-party licenses and required attribution.

## Completion

Check visual consistency and factual copy against the requested surface, inspect
responsive and semantic risks in the changed code, and identify missing assets.
Do not claim browser rendering or aesthetic feel is verified from static inspection.
The user reviews the rendered result unless they explicitly request another workflow.
